INSTRUCTIONS D'INSTALLATION (BACKEND)
=====================================

1. Aller sur https://script.google.com/home
2. Créer un nouveau projet ("Nouveau projet").
3. Copier le contenu du fichier 'appscrit.txt' et le coller dans l'éditeur (remplacer tout le code existant).
4. Sauvegarder le projet (Ctrl+S).
5. Cliquer sur "Déployer" > "Nouveau déploiement".
6. Cliquer sur la roue dentée (à gauche de "Sélectionner le type") > "Application Web".
7. Remplir les champs :
   - Description : "Sync Recettes"
   - Exécuter en tant que : "Moi" (Votre compte Google)
   - Qui peut accéder : "Tout le monde" (Important pour que le site puisse envoyer des données sans login).
8. Cliquer sur "Déployer".
9. Autoriser l'accès si demandé (Review permissions -> Choisir compte -> Advanced -> Go to ... (unsafe) -> Allow).
10. Copier l'URL de l'application Web (elle se termine par `/exec`).
11. Ouvrez `js/app.js` dans le dossier du site.
12. Cherchez la ligne `const SCRIPT_URL = "..."`.
13. Remplacez l'URL entre guillemets par votre nouvelle URL de déploiement.

NOTE IMPORTANTE :
Ce script va écrire directement dans votre document Google Doc :
https://docs.google.com/document/d/1hj6uSP1ygTEK7B6Zf9AN4bwzIVgnqslC1csFj-XyRyA/edit

Assurez-vous que le compte qui déploie le script a bien le droit d'écrire dans ce document.
