=====================================

ATTENTION : Le code du script a changé pour inclure le traçage des visiteurs.
Veuillez mettre à jour votre script Google.

1. Aller sur https://script.google.com/home
2. Ouvrez votre projet existant ("Sync Recettes").
3. Copier le contenu du fichier 'appscrit.txt' et le coller dans l'éditeur (remplacer tout le code existant).
4. Sauvegarder le projet (Ctrl+S).
5. Cliquer sur "Déployer" > "Gérer les déploiements".
6. Cliquez sur l'icône "Crayon" (Modifier) en haut à droite.
7. Dans "Version", sélectionnez "Nouvelle version".
8. Cliquez sur "Déployer". (L'URL ne devrait pas changer).
