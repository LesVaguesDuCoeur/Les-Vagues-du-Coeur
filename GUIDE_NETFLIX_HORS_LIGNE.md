# Guide : Regarder Netflix Hors-Ligne sur PC

Bonjour ! Vous avez demandé une solution pour télécharger des vidéos Netflix sur votre PC afin de les regarder hors ligne.

Il est important de noter que **le téléchargement direct de fichiers vidéo (MP4, MKV) depuis Netflix est protégé par des verrous numériques (DRM)**. Créer un script pour contourner ces protections est illégal et viole les conditions d'utilisation de Netflix.

Cependant, il existe **deux méthodes légales** pour atteindre votre objectif sur un PC (Windows). Voici comment faire :

---

## Méthode 1 : L'Application Officielle Windows (Si disponible)

Netflix propose une application sur le Microsoft Store. Historiquement, cette application permettait le téléchargement.

**Attention :** Récemment, Netflix a mis à jour son application Windows vers une nouvelle version (basée sur le web) qui a **supprimé la fonction de téléchargement** pour beaucoup d'utilisateurs.

1.  Ouvrez le **Microsoft Store** sur votre PC.
2.  Cherchez "Netflix" et installez l'application.
3.  Ouvrez l'application et connectez-vous.
4.  Cherchez le bouton **"Télécharger"** (une flèche vers le bas) sur la page d'un film ou d'une série.
    *   *Si le bouton est présent :* C'est gagné ! Cliquez dessus pour télécharger.
    *   *Si le bouton est absent :* Vous avez la nouvelle version qui ne supporte plus cette fonction. Passez à la méthode 2.

---

## Méthode 2 : L'Astuce de l'Émulateur Android (La solution robuste)

Si l'application Windows ne vous permet pas de télécharger, la meilleure solution est d'utiliser un **émulateur Android**. Cela permet de simuler une tablette Android sur votre PC. L'application mobile Netflix (Android) supporte officiellement le téléchargement hors-ligne.

### Étape 1 : Installer un émulateur
Il existe plusieurs émulateurs gratuits et populaires :
*   **BlueStacks** (Recommandé)
*   **NoxPlayer**
*   **LDPlayer**

1.  Allez sur le site officiel de **BlueStacks** (bluestacks.com) et téléchargez la version **BlueStacks 5**.
2.  Installez le logiciel sur votre PC.

### Étape 2 : Installer Netflix dans l'émulateur
1.  Lancez BlueStacks.
2.  Ouvrez l'application **Google Play Store** (vous devrez vous connecter avec un compte Google, comme sur un téléphone).
3.  Cherchez **Netflix** et installez l'application.

### Étape 3 : Télécharger vos vidéos
1.  Ouvrez l'application Netflix *dans* BlueStacks.
2.  Connectez-vous à votre compte Netflix.
3.  Allez dans les paramètres de l'application (dans BlueStacks) et réglez la qualité de téléchargement sur "Élevée".
4.  Choisissez votre film ou série.
5.  Cliquez sur le bouton **Télécharger**.

Vous pouvez maintenant regarder vos vidéos hors-ligne tant que vous lancez BlueStacks !

---

## Résumé
| Méthode | Avantages | Inconvénients |
| :--- | :--- | :--- |
| **App Windows** | Simple, natif. | La fonction téléchargement disparaît souvent. |
| **Émulateur (BlueStacks)** | **Garantie de fonctionner**, téléchargement officiel. | Demande un PC un peu puissant, installation plus longue. |

Profitez de vos séries !
